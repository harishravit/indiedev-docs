# Quick Syntax Cheat Sheets

Let's be honest: nobody memorizes every single line of code. Professional developers search for syntax rules all the time!

When you are a beginner, forgetting a bracket or an attribute can stop your progress completely. That is exactly why I built this page.

---

## Why Use This Syntax Sheet?

- **No More Forgetting:** If you forget how to center a div with Flexbox, or how to declare a type interface in TypeScript, you don't need to watch a 20-minute video again.
- **Save Your Time:** Just open this page, find the language you need, look at the code template, understand it in 5 seconds, and paste it into your project.
- **Clear Visual Examples:** Every syntax block comes with a minimal, real-world example so you instantly understand where it fits.

---

## How to Use This Section

1. Use the sidebar or navigation to pick your language (HTML, CSS, TypeScript, or React).
2. Look for the specific action you want to perform.
3. Review the quick code snippet, adapt it to your layout, and keep building!

Bookmark this page—it is going to be your most used cheat sheet while coding.
